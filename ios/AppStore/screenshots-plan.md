# Screenshot plan

App Store Connect requires 6.9" (iPhone 16 Pro Max class, 1320x2868) and
accepts 6.7"/6.5" from the same set; one size class is mandatory, others
scale. Capture on simulator once the app builds (user step - needs Xcode).

## Shot list (portrait, light mode primary, one dark-mode variant)

1. **Feed** - seeded feed showing a reaction card with tapbacks + a reply
   thread, a "finished the book" milestone, and a vote alert.
   Caption: "Every club, one feed."
2. **Book screen** - reaction composer + gated feed with the unlocked count
   visible. Caption: "Spoilers stay locked until you've read that far."
3. **My progress panel** - progress bars for several members mid-book.
   Caption: "See where everyone's bookmark is."
4. **Picker wheel** - mid-spin with the pointer visible.
   Caption: "Fate picks who chooses next."
5. **Reviews** - unlocked reviews with star ratings.
   Caption: "Reviews unlock when you finish."
6. **Clubs grid + join sheet** - the 6-character code entry.
   Caption: "Join with a code. That's it."

## Production notes

- Seed the DEV project (`npm run seed` in the repo root) for believable
  content; screenshot Debug builds (dev data, no prod exposure).
- Use `xcrun simctl status_bar override` for a clean 9:41 status bar.
- The granny-square theme is the brand: keep the parchment background,
  no device frames needed.
- 1024x1024 icon master already lives in the asset catalog (generated by
  `ios/Scripts/generate-icon.swift`).
